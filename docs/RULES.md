# 规则包说明（v1.0.0）

规则包版本：`1.0.0` ｜ 触发结果统一为"待核线索"，置信度与严重度分级见文末。

## 规则一览

| 规则 ID | 类别 | 检查内容 | 严重度/置信度 |
|---|---|---|---|
| DATE-01 | 日期数字 | 公历非法日期（如 2023年2月30日） | 高/高 |
| DATE-02 | 日期数字 | 同一日期多种写法（归一化后相同） | 低/低 |
| DATE-03 | 日期数字 | 同一行内"自X至Y"时间区间倒置 | 中/中 |
| NUM-01 | 金额 | 同句分项金额求和与"合计/共计"金额不符 | 高/高 |
| NUM-02 | 金额 | 大写金额与同段小写金额不一致 | 中/中 |
| PARTY-01 | 称谓字段 | 当事人定义名称与全文用字高度相似但不相同 | 中/中 |
| TEXT-01 | 文本异常 | 连续重复汉字（功能字重复为中置信，其余低置信） | 中/低 |
| TEXT-02 | 文本异常 | 连续重复标点 | 低/中 |
| CITE-01 | 法条引注 | 条号为 0 或明显超出合理范围（只做格式检查） | 中~低 |

## 每条线索的必备字段

规则 ID、严重度、置信度、段落号、全文字符偏移、最小必要原文摘录、
触发原因（确定性描述）、计算/比对过程（如适用）、备选解释列表、复核状态。

## 明确不做的事

- 不做错别字纠正建议（只提示重复字线索，不替代校对）；
- 不判断引注效力版本与时效；
- 不检查标点全半角规范、字体、版式（PDF/扫描件不在 MVP 范围）；
- 诉讼费速算核对需要官方费率表维护，属 M3+ 候选，未实现。

## 严重度与置信度定义

- **严重度**：线索若属实，对文书形式质量的影响程度；
- **置信度**：规则触发本身由确定性计算产生的可信程度；
- 两者都是给人工复核的排序提示，**不构成错误认定**。

## 添加新规则的约定

1. 规则必须是确定性逻辑（正则、日期合法性校验、数值比对），可解释、可复现；
2. 每条规则必须附带正例、反例、边界例测试（见 tests/test_rule_*.py）；
3. 新规则上线必须提升规则包版本号（`rules/__init__.py` 中 `RULE_PACK_VERSION`）；
4. 规则触发必须给出至少一个备选解释，把合理差异留给人工判断。
