# 数据治理说明

对应 #0029 节点 YAML"可拆零件"第 1、9 项与政策风险死法的要求。

## 输入登记（每次 lint 自动执行）

每篇被检查的文书都会在报告中携带登记记录（`document` 字段）：

- `document_id` / `sha256`：全文指纹（前 16 位作文书 ID）；
- `source_type`：固定为 `user_provided_file`——工具只接受本地文件，无任何网络输入；
- `authorization`：用户提供时声明的授权说明；
- `obtained_at`：登记时间（UTC）；
- `allowed_use`：固定为"形式异常线索检查与人工复核"；
- `formal_text_verified`：默认 `False`，提醒使用须以法院正式文本为准。

## 最小化原则

- 报告只摘录线索前后约 28 字符的最小必要原文；
- 不产生画像，不做任何自动不利处置；
- 审计日志（`audit_log.jsonl`）只记录动作、规则、理由、处理人，不复制全文。

## 撤回与删除

- 全部产物（报告、审计日志、草稿）都在用户本地，删除文件即完成撤回；
- 工具不联网、不上传，不存在平台侧撤回同步问题。

## 不做什么

- 不抓取裁判文书网或任何平台；
- 不绕过验证码、反爬、访问控制或风控；
- 不保存他人 Cookie、token、登录态；
- 不把处理结果用于个人画像。

## 真实文书使用前的合规自查（使用者责任）

1. 文书来源合法（本人案件、当事人授权、依法公开下载并符合使用条款）；
2. 已核对法院正式文本，而非转载或快照；
3. 反馈内容不含不应公开的个人信息；
4. 如需扩大数据来源或使用范围，另行进行合规审查。
